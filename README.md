# andryushkin/homebrew-apps

Homebrew tap for my macOS apps.

## EditMD

Native macOS Markdown editor — Source / Visual / Preview over one source of
truth, wiki-links, review marks, and Claude Code integration.

```sh
brew install --cask andryushkin/apps/editmd
```

The DMG is a universal (arm64 + x86_64), Developer ID signed, notarized, and
stapled build. Source and releases: https://github.com/andryushkin/editmd
